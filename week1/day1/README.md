# 🚀 Week 1 - Day 1 SQL Training

## 📌 Overview

This repository contains SQL training exercises completed during **Week 1 - Day 1**. The training focused on fundamental SQL concepts, relational database design, data insertion, and query execution using MySQL.

## 📂 Files

### 🛠️ `datacreation.sql`

* Database table creation
* Primary and foreign key implementation
* Sample data insertion

### 📊 `solutions.sql`

* SQL query solutions
* Filtering and sorting operations
* Aggregate and grouping queries

## 📚 Concepts Covered

* CREATE TABLE
* INSERT INTO
* SELECT statements
* WHERE clause
* ORDER BY
* GROUP BY
* HAVING clause
* Aggregate functions
* Relational database concepts

## 💡 Impact of the Training

This training provided practical exposure to real-world database operations and strengthened understanding of relational database management systems.

### 🔹 Key Learning Outcomes

* Improved understanding of SQL syntax and query execution
* Gained hands-on experience in database creation and management
* Learned how to establish relationships using primary and foreign keys
* Developed skills in data filtering, sorting, and aggregation
* Enhanced problem-solving ability through query-based exercises
* Built a strong foundation for advanced database and backend development concepts

## 🎯 Outcomes

By completing this training, the following outcomes were achieved:

* Successfully created and managed relational database tables
* Executed SQL queries for data retrieval and analysis
* Applied aggregate functions and grouping operations effectively
* Understood database relationships and constraints
* Improved practical knowledge of MySQL and SQL-based operations
* Developed confidence in handling structured data and query optimization

## ⚙️ Technologies Used

* SQL
* MySQL
* MySQL Workbench

## ▶️ Execution Steps

1. Run `datacreation.sql` to create tables and insert data.
2. Run `solutions.sql` to execute practice queries.
