# 🚀 Week 1 - Day 2 SQL Training

## 📌 Overview

This repository contains the SQL training exercises completed during **Week 1 - Day 2**. The training focused on employee database management, SQL query execution, data filtering, aggregation functions, grouping operations, and sorting techniques using MySQL.

## 🎯 Training Goals

* Understand SQL query execution
* Practice data retrieval and filtering operations
* Learn aggregate and grouping functions
* Perform sorting and analytical queries
* Strengthen relational database concepts

## 🛠️ Files Included

### 📄 `data_creation.sql`

Contains:

* Employee table creation
* Sample employee records
* Department, salary, city, and experience data

### 📄 `solution.sql`

Contains SQL queries for:

* Data retrieval using SELECT
* Filtering using WHERE clause
* Aggregate functions
* GROUP BY and HAVING clauses
* Sorting using ORDER BY
* Limiting results using LIMIT
* DISTINCT operations

## 📚 Concepts Covered

* CREATE TABLE
* INSERT INTO
* SELECT statements
* WHERE clause
* GROUP BY
* HAVING clause
* ORDER BY
* LIMIT
* DISTINCT
* Aggregate functions:

  * COUNT()
  * SUM()
  * AVG()
  * MAX()
  * MIN()

## 🧪 Practice Topics

* Employee database creation
